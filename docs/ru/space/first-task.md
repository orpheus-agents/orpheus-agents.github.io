# Первое задание

Проверьте весь путь от расписания до ответа агента после [подключения Orpheus](setup.md). В локальном примере откройте `http://localhost:8086`.

1. В **Заданиях** нажмите **Новое задание**. Название — `Проверка Space`, **Задание агенту** — `Ответь SPACE_OK. Никуда не отправляй сообщения.`
2. В поле **Повторять** выберите **Каждые несколько минут**, затем **Каждую минуту**. Проверьте часовой пояс и будущие запуски.
3. Выберите **Новая сессия для каждого запуска** и статус **Работает**. Модель оставьте пустой. Если есть блок дополнительных ENV, ничего в нём не выбирайте. Сохраните задание.
4. Дождитесь следующей минуты. Откройте задание: в **Истории запусков** появится срабатывание. Когда оно получит статус отправки **Принят**, нажмите **Пауза**, чтобы больше не создавать запусков. Принятый запуск продолжит работу.
5. Откройте запись истории. Дождитесь сохранённого статуса **Завершён**, обновляя страницу при необходимости. Нажмите **Загрузить результат**: итоговый ответ должен содержать `SPACE_OK`.
6. Удалите тестовое задание. Его история сохранится, но новых срабатываний не будет.

Если отправка остаётся в состоянии **Отправляется**, проверьте код ошибки в карточке. `core_unavailable` указывает на недоступный адрес Orpheus. Если запуск принят, но не выполняется, проверьте worker Orpheus. [Диагностика](operations.md#diagnostics).
