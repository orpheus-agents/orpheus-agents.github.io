# Первое задание

Проверьте весь путь от расписания до ответа агента после [подключения Orpheus](setup.md). В локальном примере откройте `http://localhost:8086`.

1. В **Заданиях** нажмите **Новое задание**. Название — `Проверка Space`, **Задание агенту** — `Ответь SPACE_OK. Никуда не отправляй сообщения.`
2. В поле **Повторять** выберите **Каждые несколько минут**, затем **Каждую минуту**. Проверьте часовой пояс и будущие запуски.
3. Выберите **Новая сессия для каждого запуска** и статус **Пауза**. Модель оставьте пустой. Сервисы оставьте невыбранными. Сохраните задание.
4. В карточке сохранённого задания нажмите **Запустить сейчас**. В **Истории запусков** появится срабатывание с отметкой **Вручную**. Задание останется на паузе, поэтому cron не создаст следующих запусков.
5. Откройте запись истории. Дождитесь сохранённого статуса **Завершён**, обновляя запись при необходимости. Результат загружается автоматически при открытии записи. Его итоговый ответ должен содержать `SPACE_OK`.
6. Удалите тестовое задание. Его история сохранится.

Перед удалением задания можно проверить и автоматическое выполнение: возобновите его, дождитесь следующей минуты и снова поставьте на паузу после принятия срабатывания. [Пауза не отменяет принятую работу](schedules.md#pausing).

Если отправка остаётся в состоянии **Отправляется**, проверьте код ошибки в карточке. `core_unavailable` указывает на недоступный адрес Orpheus. Если запуск принят, но не выполняется, проверьте worker Orpheus. [Диагностика](operations.md#diagnostics).
