# Orpheus Space

Space — пространство пользователей агентов Orpheus. В нём задают регулярные поручения: собрать утренний отчёт, проверить очередь обращений или подготовить сводку за неделю. В назначенное время Space передаёт задачу Orpheus и показывает историю выполнения.

У Space отдельный веб-интерфейс и [вход через SSO](access.md). Сотрудникам можно разрешить вход в Space, не предоставляя доступ к веб-интерфейсу Orpheus для администраторов.

Итоговый ответ доступен из истории задания. Space сам не отправляет его в мессенджер. Для публикации укажите адрес назначения в поручении и дайте агенту нужные инструменты и доступы.

## Как пользоваться

1. Откройте **Задания** и создайте поручение. Укажите, что агент должен сделать и где оставить результат.
2. Выберите повторение и часовой пояс. Проверьте ближайшие срабатывания.
3. Сохраните задание в статусе **Работает** или **Пауза**.
4. После срабатывания откройте историю и получите результат запуска.

Все пользователи с доступом к Space видят и редактируют все задания. Email владельца помогает фильтровать список, но не ограничивает права. Пустой email обозначает общее задание.

Расписания можно создавать и обычным сообщением агенту, если администратор установил [CLI и навык Space](cli.md). Навык предписывает агенту работать только с заданиями автора запроса. Эти правила не заменяют серверное разграничение доступа.

## Как устроено подключение

```text
Браузер → Space Web → Space API → БД Space
Агент → CLI Space → Space API
Space worker → Orpheus → AgentBox
```

Space хранит расписания и наблюдаемые статусы запусков. Полные результаты остаются в Orpheus. Список и история доступны без обращения к Orpheus, а кнопка получения результата делает отдельный запрос.
