# Развёртывание на сервере

Для одной инсталляции используйте [Compose-комплект быстрого старта](../getting-started/launch.md). Он запускает PostgreSQL, миграции, API, worker, Mattermost-коннектор и веб-интерфейс.

## Подготовьте сервер

1. Установите Docker Engine, Compose и Git.
2. Скопируйте комплект в отдельный рабочий каталог.
3. Создайте конфигурацию, заполните ключи и подключение Mattermost.
4. Проверьте исходящий доступ worker к AgentBox и песочниц к используемым системам.
5. Запустите сервисы и проверьте первую задачу.
6. Настройте [HTTPS](network.md), [SSO](sso.md) и [резервное копирование](backup.md).

Для первичной проверки удалённого сервера откройте SSH-туннель:

```sh
ssh -L 8085:127.0.0.1:8085 user@your-server
```

Затем откройте `http://localhost:8085` на своём компьютере.

## Постоянная работа

Включите запуск Docker после перезагрузки. Комплект использует `restart: unless-stopped` для постоянных сервисов. Миграции должны успешно завершиться до запуска API и worker.

Вместо встроенной БД можно указать внешний PostgreSQL в [`DATABASE_URL`](../reference/environment.md#env-database-url) на API, worker и миграциях. Сохраните одинаковые TOML-профили, ключ шифрования и список разрешённых переменных для API и worker.

Запускайте один Mattermost-коннектор на сервер и бота. При переносе в Kubernetes сохраняйте это правило, отдельный шаг миграций и настройки проксирования SSE.
