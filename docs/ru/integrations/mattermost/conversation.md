# Диалог, контекст и уточнения

Бот работает в треде. При первом обращении коннектор передаёт контекст разговора, а при продолжении добавляет новые сообщения. Для этого Mattermost автоматически создаёт сессии с [`allow_multiple_runs: true`](../../reference/api/create-session.md). Настраивать этот флаг в workflow не требуется.

| Действие | Что происходит |
| --- | --- |
| Упомянуть бота в новом треде | Создаётся сессия и первый запуск |
| Упомянуть во время работы | Агент получает уточнение в текущем запуске |
| Упомянуть после завершения | Начинается следующий запуск с контекстом |
| Вернуться после удаления песочницы | Создаётся новая сессия с контекстом из треда |

Пример уточнения: `@orpheus Учти, что отчёт нужен только по активным клиентам.` Оно может скорректировать дальнейшую работу, но не отменяет уже выполненные действия.

Коннектор публикует завершённые промежуточные сообщения и итоговый ответ. Чтобы оставить только ответы, задайте [`send_commentary_messages: false`](../../reference/mattermost.md#workflow-send-commentary-messages).

Ограничьте начальный контекст через [`initial_context_token_budget`](../../reference/mattermost.md#workflow-initial-context-token-budget). Это приблизительный бюджет, отдельно действует ограничение размера API-запроса. Важное требование лучше повторить в текущем обращении.

При исчерпании бюджета, удалении песочницы, потере окружения или смене ревизии следующий запрос создаёт новую сессию. Для песочниц на паузе действует [срок хранения](../../configuration/sandbox-retention.md), по умолчанию 14 дней с завершения последнего запуска. Коннектор собирает заново доступный контекст треда и вложения. Файлы, созданные только внутри прежнего окружения, восстановить нельзя. Важный для задачи документ приложите или дайте ссылку повторно.

Если удаление совпало с отправкой запроса, коннектор перечитывает историю принятия перед переносом непринятого входа в новую сессию. Принятый запуск, завершившийся с `sandbox_lost`, публикуется как ошибка без автоматического повтора. Для продолжения отправьте новый запрос.

Недоставленное уточнение из успешно завершённого запуска может перейти в следующий запуск. Если для него нужна новая сессия, коннектор сохраняет исходный текст уточнения и восстанавливает вложения и доступный контекст, включая предыдущий итоговый ответ. Более новые непринятые упоминания не добавляются в контекст переносимого уточнения. Ввод из упавших или отменённых запусков не переносится. Если он ещё нужен, отправьте новый запрос.

## Автор сообщения {#identity}

Коннектор передаёт автора и канал отдельно для каждого поста. [Навык Space](../../space/cli.md) использует email автора текущей просьбы, чтобы выбрать его задания. [Формат метаданных и доступность email](../../reference/mattermost.md#identity).
