# Подключение своей системы

Коннектор переводит события вашей системы в задачи для Orpheus. Он может быть небольшим сервисом, обработчиком webhook или периодическим заданием.

```text
Новый тикет → коннектор → POST /sessions → агент
                                            ↓
Хелпдеск ← API-вызов агента или after_run ← результат
```

## Разделите обязанности

| Ваша интеграция | Orpheus | Агент |
| --- | --- | --- |
| Выбирает события и собирает контекст | Запускает выполнение и сохраняет историю | Решает задачу доступными инструментами |
| Связывает объект с сессией | Принимает новые задачи и уточнения | Готовит ответ или файл |
| Определяет доставку и повторы | Возвращает состояния, события и результаты | Следует заданным инструкциям |

Входом API служит массив текстовых сообщений. Файлы подготавливаются отдельно в песочнице. Источник задач и целевая система не обязаны совпадать.

Для простого коннектора достаточно создавать отдельную сессию по каждому событию. Для чатового коннектора выберите [`allow_multiple_runs: true`](../../reference/api/create-session.md), чтобы [продолжать диалог](continuation.md) в одной сессии. Настройте [доставку результата](results.md) и [обработку повторов](reliability.md).

Примеры используют Python и стандартную библиотеку. Они показывают отдельные операции, а не готовый webhook-сервер. Для Go доступен [клиент Orpheus](https://github.com/orpheus-agents/orpheus/tree/main/client).
