# Сообщения, инструменты и хуки

История помогает понять, откуда взялся ответ и на каком этапе возникла ошибка.

| Элемент | Что смотреть |
| --- | --- |
| Сообщение пользователя | Текст задачи и переданный контекст |
| Сообщение агента | Промежуточное пояснение или итоговый ответ |
| Вызов инструмента | Аргументы, команда, результат и код завершения |
| Хук | Подготовка данных или отправка результата |
| Технический журнал | Состояния и служебные события |

Входные параметры инструмента видны до завершения вызова. Вывод раскрывается отдельно. Большие сообщения и результаты могут требовать раскрытия. При усечении вывода интерфейс показывает это явно.

Если агент подготовил ответ, а доставка не состоялась, проверьте [`after_run`](../configuration/hooks.md#hook-after-run). Если агент не приступил к задаче, смотрите подготовку окружения и [`before_run`](../configuration/hooks.md#hook-before-run).

История подгружается страницами. Для длинных запусков используйте загрузку предыдущих элементов или HTTP API истории. Вложенные изображения в Markdown представлены ссылками, чтобы просмотр истории не отправлял фоновые запросы сторонним серверам.
