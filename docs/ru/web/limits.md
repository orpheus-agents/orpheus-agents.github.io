# Токены и лимиты аккаунтов

Раздел лимитов показывает квоты аккаунтов, используемых профилями с [`mode = "account"`](../configuration/authentication.md#аккаунт). Квоты API-ключей в этом списке не отображаются.

| Состояние | Как читать |
| --- | --- |
| `fresh` | Есть актуальное наблюдение |
| `stale` | Сохранённые данные устарели, смотрите время наблюдения |
| `unknown` | Успешного наблюдения нет |
| `unavailable` | Данные не удалось получить |

Пустое значение не означает нулевой расход. Обновления приходят от работающих сессий соответствующего аккаунта. Просмотр страницы не пробуждает спящую песочницу.

Несколько профилей одного аккаунта объединяются по [`account_id`](../reference/profiles.md#profile-auth-account-id). Процент использования относится к окну квоты провайдера. Смотрите длительность окна и время сброса.

## Разбивка токенов

Входные токены включают кешированные, выходные включают токены рассуждения. Не складывайте подкатегории с общими счётчиками второй раз.

Лимиты аккаунта служат наблюдению и не заменяют [бюджет сессии](../configuration/limits.md). Отсутствие свежего наблюдения не является основанием считать доступную квоту бесконечной.
