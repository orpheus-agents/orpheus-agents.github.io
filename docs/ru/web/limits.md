# LLM-аккаунты и лимиты

В **Настройки → LLM-аккаунты** аккаунты представлены карточками с лимитами. Используйте поиск по названию, фильтр активности и пагинацию. В карточке видны название, харнес, режим авторизации, активность и связанные профили, а также все доступные окна квот, время сброса и свежесть наблюдений.

Откройте карточку, чтобы изменить название или авторизацию, включить, выключить или удалить аккаунт. Удаление запрещено, пока на него ссылаются профили или сессии. API-ключи отображаются только маской. [Настроить авторизацию](../configuration/authentication.md).

Наблюдения квот провайдера доступны для файловой авторизации. Аккаунты с API-ключом остаются в списке без этих квот. Ошибка запроса отображается отдельно от успешного ответа без наблюдения.

| Состояние | Как читать |
| --- | --- |
| `fresh` | Есть актуальное наблюдение |
| `stale` | Сохранённые данные устарели, смотрите время наблюдения |
| `unknown` | Успешного наблюдения нет |
| `unavailable` | Данные не удалось получить |

Пустое значение не означает нулевой расход. Обновления приходят от работающих сессий соответствующего аккаунта. Просмотр страницы не пробуждает спящую песочницу.

Аккаунт определяется по [`account_id`](../reference/profiles.md#profile-auth-account-id). Процент использования относится к окну квоты провайдера. Смотрите длительность окна и время сброса.

## Разбивка токенов

Входные токены включают кешированные, выходные включают токены рассуждения. Не складывайте подкатегории с общими счётчиками второй раз.

Лимиты аккаунта служат наблюдению и не заменяют [бюджет сессии](../configuration/limits.md). Отсутствие свежего наблюдения не является основанием считать доступную квоту бесконечной.
