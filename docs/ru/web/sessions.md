# Сессии и запуски

Откройте список сессий, чтобы найти диалог или проверить незавершённую задачу. Используйте фильтры активности, состояния, [namespace и внешнего ключа](../reference/api/list-sessions.md). Сортировка по последнему запуску помогает найти недавно обновлённые разговоры.

В карточке сессии видны профиль, модель, состояние песочницы, расход токенов и запуски. Выберите запуск, чтобы посмотреть именно его сообщения, инструменты и хуки.

## Пример поиска проблемы

1. Найдите namespace `mattermost/assistant` или `helpdesk`.
2. Откройте сессию нужного треда или тикета.
3. Выберите последний запуск.
4. Проверьте состояние и фазу ошибки.
5. Перейдите к неуспешному инструменту или хуку.

Сессия отражает состояние своей работы. После завершения запуска разговор можно продолжить, если сессия создана с [`allow_multiple_runs: true`](../reference/api/create-session.md).

Ссылку на карточку можно передать коллеге с доступом к веб-интерфейсу. История общая для допущенных пользователей. При разрыве соединения интерфейс восстанавливает обновления, но доступность сервера стоит проверять по индикатору подключения.
