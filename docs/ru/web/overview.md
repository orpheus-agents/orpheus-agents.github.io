# Обзор активности

Веб-интерфейс помогает увидеть текущую нагрузку и результаты работы агентов. Откройте его по адресу своей инсталляции. В быстром старте это `http://localhost:8085`.

На странице аналитики выберите период. Показатели включают число запусков, текущие активные сессии, токены и суммарное время работы. График показывает распределение активности по часам или дням.

Разбивка по [namespace](../reference/api/get-analytics-overview.md) помогает сравнить процессы: например, Mattermost и хелпдеск. Нажмите namespace, чтобы отфильтровать страницу.

## Как читать показатели

- В выбранный период попадают запуски, принятые в этот период.
- Текущие активные сессии показывают нагрузку сейчас, независимо от диапазона.
- Суммарное время складывается по запускам. Параллельные задачи могут дать сумму больше длительности периода.
- Токены отражают сохранённые отчёты агента. Денежная стоимость здесь не рассчитывается.

Веб-интерфейс предоставляет просмотр. Задачи создаются через Mattermost или API интеграции.
