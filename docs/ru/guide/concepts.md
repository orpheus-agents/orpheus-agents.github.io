# Основные понятия

| Понятие | Значение | Пример |
| --- | --- | --- |
| Агент | Исполнитель задачи с моделью, инструкциями и инструментами | Помощник оператора поддержки |
| Профиль | Именованная настройка модели и авторизации | `default`, `deep-analysis` |
| Workflow | Настройки маршрутизации Mattermost и инструкции агенту | Помощник канала поддержки |
| Сессия | Контекст диалога и рабочее окружение | Обработка одного тикета |
| Запуск, run | Одна задача внутри сессии | Подготовка первоначального ответа |
| Уточнение | Новая информация работающему агенту | Дополнительный текст ошибки |
| Песочница | Окружение с файлами и инструментами | Агент Codex в AgentBox |
| Шаблон | Подготовленный набор программ песочницы | Codex, Python и CLI хелпдеска |
| Хук | Скрипт подготовки или завершения работы | Публикация файла ответа |
| Namespace | Метка интеграции или процесса | `helpdesk` |

В сессии выполняется один запуск за раз. Во время работы можно передать уточнение. После завершения можно начать следующий запуск с сохранённым контекстом. Конфигурация сохраняется при создании сессии: смена профиля не перенастраивает существующий диалог.
