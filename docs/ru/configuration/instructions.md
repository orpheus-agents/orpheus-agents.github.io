# Инструкции агенту

Инструкции определяют задачу агента, источники данных и ожидаемый результат. Отделяйте их от текста обращения пользователя.

```text
Ты помогаешь оператору поддержки.
Изучи тикет и найди подходящий раздел базы знаний.
Если данных недостаточно, перечисли вопросы оператору.
Подготовь внутренний комментарий: причина, проверка, проект ответа.
Не отправляй сообщение клиенту и не меняй статус тикета.
```

Общие инструкции можно задать строкой [`instructions`](../reference/profiles.md#profile-instructions) в профиле. В API поле [`configuration.agent.instructions`](../reference/api/create-session.md) заменяет инструкции профиля, если передано. В Mattermost тело Markdown-файла workflow передаётся как инструкции: включайте в него все правила, необходимые этому помощнику.

## Что включить

- Роль и границы задачи.
- Какие инструменты использовать для получения сведений.
- Когда запросить недостающие данные.
- Куда сохранить или отправить результат.
- Какие действия требуют участия человека.

Для результатов в файлах задайте путь и формат. Для Mattermost включите правило чтения [`current-run.json`](../integrations/mattermost/files.md) и записи в outbox из [примера workflow](../integrations/mattermost/workflow.md).

Проверяйте инструкции на реальных задачах. Запрет в тексте полезно подкреплять соответствующими правами API-токена.
