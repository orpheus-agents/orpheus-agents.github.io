# Навыки, CLI и MCP

Корпоративные инструменты устанавливаются в окружение агента. Orpheus выбирает подготовленный шаблон и передаёт разрешённые доступы.

| Способ | Когда использовать | Что подготовить |
| --- | --- | --- |
| HTTP API | Несколько простых операций | Описание запросов, адрес и токен |
| CLI | У системы есть удобная командная утилита | Утилиту, зависимости и краткую инструкцию |
| MCP | Инструменты предоставляет MCP-сервер | Конфигурацию клиента Codex и доступ к серверу |
| Навык | Нужна повторяемая процедура | Инструкции и вспомогательные файлы |

Например, помощнику поддержки можно установить CLI хелпдеска и навык поиска информации в базе знаний. Инструкция описывает порядок работы, а токен ограничивает доступные операции.

Добавляйте инструменты по [инструкции создания шаблона](https://docs.agentbox.ru/ru/templates/definition/). Конфигурацию Codex и навыки размещайте в путях, которые использует установленный в шаблоне агент. Проверьте их обнаружение внутри новой песочницы.

Не включайте реальные секреты в образ. Передавайте их через [переменные окружения](secrets.md). После сборки выполните тестовую задачу и проверьте вызовы инструментов в истории.
