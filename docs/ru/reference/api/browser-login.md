# Вход через SSO

```http
GET /auth/login
```

Только режим SAML, иначе 404 auth_not_enabled. next должен быть локальным абсолютным путём вне маршрутов авторизации. По умолчанию /api/v1/auth/session. Host и заголовки proxy не определяют адрес возврата.

**operationId:** `browser_login`

## Авторизация

Без авторизации API-ключом.

Условия браузерного доступа: [авторизация](../../operations/sso.md). Изменяющие данные запросы к сессиям требуют Bearer-ключ.

## Параметры

| Имя | Где | Обязательный | Тип | Описание и ограничения |
| --- | --- | --- | --- | --- |
| `next` | query | Нет | string |  maxLength: <code>2048</code> |

## Ответы

| Код | Описание | Содержимое |
| --- | --- | --- |
| 302 | Начать вход SAML по инициативе SP |  |
| default | Неверный путь возврата (400), авторизация отключена (404), ошибка проверки запроса (422) или недоступность авторизации/хранилища (503). | `application/json`: [ErrorResponse](schema-errorresponse.md) |

### Заголовки ответа 302

- `Location`: Адрес SAML IdP. string
