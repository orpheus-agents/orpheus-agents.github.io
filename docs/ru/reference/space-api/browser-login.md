# Вход через SAML

```http
GET /auth/login
```

Доступно в режиме saml. В остальных режимах возвращает 404 auth_not_enabled. next — локальный абсолютный путь, кроме маршрутов авторизации. По умолчанию /api/v1/auth/session. Адрес входа не определяется заголовками Host или прокси.

**operationId:** `BrowserLogin`

## Авторизация

Без авторизации API-ключом.

Условия доступа, браузерной записи и SAML callback: [авторизация Space](../../space/access.md).

## Параметры

| Имя | Где | Обязательный | Тип | Описание и ограничения |
| --- | --- | --- | --- | --- |
| `next` | query | Нет | string |  maxLength: <code>2048</code> |

## Ответы

| Код | Описание | Содержимое |
| --- | --- | --- |
| 302 | Вход через SAML |  |
| default | Некорректный путь возврата (400), авторизация отключена (404), ошибка валидации (422) или недоступность авторизации/хранилища (503). | `application/json`: [Problem](schema-problem.md) |

### Заголовки ответа 302

- `Location`: Адрес SAML IdP. string
