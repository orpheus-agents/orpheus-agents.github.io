# Обработка подписанного SAML-ответа

```http
POST /auth/callback
```

Только режим saml. Тело application/x-www-form-urlencoded содержит ровно по одному SAMLResponse и RelayState и занимает не более 1 MiB. Нужны одноразовый запрос и браузерный nonce. Ответы без начатого входа отклоняются.

**operationId:** `BrowserCallback`

## Авторизация

Без авторизации API-ключом.

Условия доступа, браузерной записи и SAML callback: [авторизация Space](../../space/access.md).
