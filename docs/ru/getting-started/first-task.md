# Первая задача и проверка результата

Убедитесь, что бот ответил в исходном треде. Затем откройте веб-интерфейс и найдите сессию с namespace `mattermost/assistant`.

1. Откройте последний запуск. Дождитесь состояния `completed`.
2. Сравните входное сообщение и ответ с тредом Mattermost.
3. Посмотрите расход токенов и время работы.
4. В том же треде попросите бота уточнить один пункт, снова упомянув его. В сессии появится следующий запуск.
5. Прикрепите небольшой текстовый файл и попросите сделать краткое содержание. Затем попросите подготовить результат в Markdown-файле.

Текст уточнения во время работы передаётся текущему запуску. Новая задача после завершения создаёт следующий запуск.

## Остановка

```sh
docker compose down
```

База данных сохраняется в volume. Для повторного запуска выполните `docker compose up -d`. Не добавляйте `-v` к остановке, если хотите сохранить историю.

Далее настройте [профили](../configuration/profiles.md) и [workflows по каналам](../integrations/mattermost/channels.md).
